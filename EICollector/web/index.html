수집 팁 · 단축키
  • Edge Impulse 이미지 분류는 정사각형 입력(96×96, 160×160)을 많이 씁니다. 240×240으로 찍으면 잘리는 부분 없이 줄어듭니다.
  • 클래스마다 비슷한 장수(최소 50장 이상)를 모으고, 물체가 없는 background 클래스도 만드세요.
  • 각도·거리·조명·배경을 바꿔 가며 찍으면 모델이 덜 헷갈립니다.
  • 파일 이름이 클래스.시각.jpg라서 Edge Impulse에 올리면 라벨이 자동으로 붙습니다.
  • Space 찍기 · B 연속 촬영 · Esc 연속 촬영 중지 · 1~9 클래스 선택 · Delete 선택 삭제 · Ctrl+Z 삭제 되돌리기
